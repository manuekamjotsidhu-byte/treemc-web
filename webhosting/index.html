What does TreeMC Web Hosting include?

Starter Web (₹100/mo) includes 25% High Clock vCPU, 4 GB RAM, and 5 GB Fast Disk; Pro Web (₹200/mo) doubles CPU and disk to 50% High Clock vCPU, 6 GB RAM, and 10 GB Fast Disk. Both include Unmetered Bandwidth, Free SSL, DDoS mitigation, and cPanel & Pterodactyl panel access.

Can I host a Minecraft store, documentation site, or Node/PHP web app?

Yes. TreeMC Web Hosting supports static sites, PHP/cPanel sites, community forums, and custom web apps via cPanel & Pterodactyl. Ask our Discord team if your app requires custom ports or extra disk.

Do I need a VPS instead of Web Hosting?

Choose Web Hosting for websites and web apps that do not need root OS access. If you need full root Linux control, Docker, or custom background services, compare our Cloud VPS plans.
