How to set up an ARK: Survival server

By TreeMC · Updated 17 November 2026

An ARK server keeps your tribe's dinos and bases alive around the clock. This guide covers ARK: Survival Evolved and the same ideas apply to Ascended.

1. Plan and map

ARK needs at least 6 GB of RAM for a small group and more with mods and many tames. Choose your map (The Island, Ragnarok, Valguero and so on) in the panel's Startup tab before the first start; changing maps later starts a new world. Plans are on the game hosting page.

2. Join

The first start downloads and builds the map, which can take a few minutes. When the console shows the server is up:

  • Steam: open Steam → View → Game Servers → Favorites → Add a server → enter IP:query-port, then connect from there or find it in ARK's server browser under Favorites.
  • Default ports are 7777 UDP (game) and 27015 UDP (query). Your panel shows the real ones.

3. Change rates and settings

Stop the server, then edit ShooterGame/Saved/Config/LinuxServer/GameUserSettings.ini (or WindowsServer). Under [ServerSettings]:

SettingWhat it does
ServerPasswordPassword to join.
ServerAdminPasswordPassword for admin commands. Make it long.
XPMultiplierXP gain. 2.0 is double.
TamingSpeedMultiplierHow fast dinos tame.
HarvestAmountMultiplierResources per hit.
DifficultyOffset and OverrideOfficialDifficultyWild dino levels. OverrideOfficialDifficulty=5.0 gives max level 150.
MaxPlayers (under [/Script/Engine.GameSession])Player slots.

Breeding and mating speeds live in Game.ini under [/script/shootergame.shootergamemode], for example MatingIntervalMultiplier=0.5 and EggHatchSpeedMultiplier=5.0.

4. Become admin

In game, press Tab to open the console and type enablecheats YourAdminPassword. Now admin commands work with the admincheat prefix, for example admincheat fly or admincheat saveworld.

5. Add mods

  1. Find each mod's ID on its Steam Workshop page (the number in the address).
  2. Add them to ActiveMods= under [ServerSettings], separated by commas, in load order.
  3. Restart. The server downloads the mods, and players get them when they join.

Keep regular backups, especially before updates and new mods.
