How to install Minecraft plugins and mods

By TreeMC · Updated 17 November 2026

Plugins run on the server only, so players join with a normal Minecraft client. Mods change the game itself, so every player needs the same mods installed. Pick one approach per server.

Install plugins (Paper, Spigot, Purpur)

  1. Make sure the server runs Paper (or Spigot or Purpur). Vanilla cannot load plugins.
  2. Download the plugin .jar from a trusted site: Hangar, Modrinth or SpigotMC. Check that it supports your Minecraft version.
  3. Stop the server.
  4. Open the Files tab and upload the .jar into the plugins folder.
  5. Start the server. The console lists every plugin it loads. Type plugins in the console to see them; green names are working.
  6. The plugin creates its own folder in plugins/ with a config.yml. Edit it, then restart or use the plugin's reload command.

Good first plugins: LuckPerms (permissions), EssentialsX (homes, warps, kits), CoreProtect (see and roll back griefing), Chunky (pre-generate the world so exploring does not lag) and Geyser (Bedrock crossplay).

Install mods (Forge, NeoForge, Fabric)

  1. Choose the mod loader the mods need. Forge, NeoForge and Fabric mods do not mix.
  2. Set the server to that loader and the exact Minecraft version, then start it once so it creates its folders.
  3. Stop the server and upload the mod .jar files into the mods folder. Many mods need a library mod too (Fabric API for Fabric).
  4. Start the server and watch the console for errors.
  5. Every player installs the same loader, version and mods on their own client. A launcher like Prism or the CurseForge app makes this easy, and a ready modpack keeps everyone in sync.

Some mods are client only (minimaps, shaders). They do not belong on the server and can stop it from starting.

How much RAM do plugins and mods need?

A light plugin server is fine on 3 to 4 GB. Large modpacks often need 6 to 10 GB. See how much RAM you need.

A plugin or mod will not load

  • Wrong version: the console says it was built for a different Minecraft or Java version. Download the matching release.
  • Missing dependency: the error names another plugin or library it needs. Install that too.
  • Duplicate: two versions of the same jar are in the folder. Delete the old one.
  • Crash on start: remove the newest jar, start again, and add plugins back one at a time to find the bad one.

Only download from the sites above. A jar from an unknown link can contain malware that steals your server or world. Make a backup before adding big plugins or mods.
