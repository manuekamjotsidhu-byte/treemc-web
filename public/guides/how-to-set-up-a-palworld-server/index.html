How to set up a Palworld server

By TreeMC · Updated 17 November 2026

A dedicated Palworld server keeps your world online even when the host player is offline, and lets up to 32 players join. Here is everything from picking a plan to keeping it running smoothly.

1. Choose a plan

Palworld is heavy on memory. A small group of friends is happy on 6 GB with a daily restart; bigger groups want 8 to 16 GB. Full details are in how much RAM you need. Pick a location close to your players for the lowest ping. Plans are on the Palworld hosting page.

Server requirements

  • RAM: 6 GB minimum, 8 to 16 GB for bigger groups.
  • CPU: 3 or more fast cores. Big bases with many working Pals use a lot of CPU.
  • Disk: about 15 GB for the server plus your saves and backups.
  • Network: the game port, 8211 UDP by default.

2. Join your server

  1. Start the server from the panel and wait for the console to finish loading.
  2. In Palworld, choose Join Multiplayer Game.
  3. At the bottom, type your server's IP:port and press Connect. Enter the server password if you set one.

3. Change server settings

Settings live in Pal/Saved/Config/LinuxServer/PalWorldSettings.ini. If the file is empty, copy the contents of DefaultPalWorldSettings.ini from the server folder into it first. Stop the server before editing, and keep everything on the single long OptionSettings=(...) line.

SettingWhat it does
ServerName, ServerDescriptionName and text shown to players.
ServerPasswordPassword to join. Leave empty for an open server.
AdminPasswordLets you use admin commands in game after /AdminPassword yourpassword.
ServerPlayerMaxNumMaximum players, up to 32.
ExpRate, PalCaptureRateXP and capture multipliers. 1.000000 is normal, 2.000000 is double.
DeathPenaltyNone, Item, ItemAndEquipment or All.
DayTimeSpeedRate, NightTimeSpeedRateHow fast day and night pass.
bIsPvPTrue lets players fight each other.

Save and start the server. If your changes vanish, the server was running while you edited, or the line was broken by a missing bracket or comma.

4. Back up and restore your world

Your world is in Pal/Saved/SaveGames/0/, in a folder with a long ID.

  • Back up: use the Backups tab in the panel, or stop the server and download that folder as a zip. Keep a few days of copies.
  • Restore: stop the server, replace the world folder with your backup (same folder name), then start it.
  • Move a co-op world to the server: upload the world folder, then set DedicatedServerName in Pal/Saved/Config/LinuxServer/GameUserSettings.ini to that folder's name. Player characters from co-op may need to be recreated, because the host's save is stored differently.

More on backups for every game: back up and restore a game server.

5. Schedule automatic restarts

Palworld's memory use climbs over time, which causes lag and crashes on long-running servers. A daily restart fixes it.

  1. Open the Schedules tab in the panel and create a schedule, for example every day at 5:00 AM when few people play.
  2. Add a task to send a warning message (for example Broadcast Server_restarting_in_5_minutes if you use RCON), then a Restart power action a few minutes later.
  3. Make a backup task run just before the restart.

The game saves automatically, but a backup right before the restart means you never lose more than a day.
