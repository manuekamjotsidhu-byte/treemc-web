How to make a Minecraft server

By TreeMC · Updated 17 November 2026

This guide takes you from nothing to a running Minecraft server your friends can join. It covers hosted servers (the easy way) and the few things that change when you host at home.

1. Create the server

  1. Pick a plan. 2 to 4 GB of RAM is enough for a small group on Vanilla or Paper. Plugins and mods need more, see how much RAM you need. Plans are on the Minecraft hosting page.
  2. Choose the server software. Paper is the best default for Java: it runs Vanilla worlds faster and supports plugins. Pick Forge or Fabric only if you want mods, and Bedrock only if every player is on phone, console or Windows Bedrock.
  3. Choose the version your players use, for example 1.21. Everyone has to join on the same version unless you add a plugin like ViaVersion.
  4. Start the server from the Console tab of the control panel. The first start creates the world and the config files. When the console says Done, it is ready.
  5. Accept the EULA if the console asks: open eula.txt in the Files tab, change eula=false to eula=true, save and start again.

2. Join your server

Your server address is shown at the top of the panel, for example play.example.in:25565 or an IP and port.

  • Java: Multiplayer → Add Server → paste the address → Done → join. If the port is 25565 you can leave it out.
  • Bedrock (phone, console, Windows): Play → Servers → Add Server, then put the address and the port in separate boxes. To let Bedrock players join a Java server, set up Geyser and Floodgate.

Cannot connect? Check Minecraft server errors and fixes.

3. Give yourself OP (admin)

OP lets you use commands like /gamemode, /tp and /ban. In the panel Console, type the command without a slash:

op YourMinecraftName

To remove it, use deop YourMinecraftName. Only give OP to people you trust: an operator can ban anyone, change the world and stop the server. With LuckPerms on Paper you can give smaller permissions instead of full OP.

4. server.properties explained

Most settings live in server.properties in the Files tab. Stop the server, edit, save, then start it again.

SettingWhat it does
motdThe text under your server name in the server list.
max-playersHow many players can be online at once.
difficultypeaceful, easy, normal or hard.
gamemodeDefault mode for new players: survival, creative, adventure.
pvptrue lets players hurt each other.
white-listtrue means only players you add with whitelist add Name can join.
online-modeKeep true. It checks that players own Minecraft and stops people joining under someone else's name.
view-distanceHow many chunks are sent to players. Lower it (6 to 8) if the server lags.
simulation-distanceHow far away mobs and farms keep working. Lowering it saves a lot of CPU.
spawn-protectionRadius around spawn that only OPs can build in. 0 turns it off.
level-seedThe seed for a new world. Only used when the world is created.
level-nameThe folder name of the world the server loads.

5. Upload or import a world

  1. Stop the server.
  2. On your PC, find the world folder. For single player Java it is in .minecraft/saves/. Zip the folder.
  3. In the Files tab, rename or delete the old world folder (make a backup first).
  4. Upload your zip, then unarchive it so you have a folder that contains level.dat.
  5. Rename that folder to world, or set level-name in server.properties to its name.
  6. Start the server.

Upload a world from the same or an older Minecraft version. Loading a world in an older version than it was saved in can corrupt it. Paper splits the Nether and End into world_nether and world_the_end; Vanilla keeps them inside world, and Paper moves them for you on first start.

6. Do you need port forwarding?

Not on a hosted server. Your server already has a public address, so there is nothing to forward.

Port forwarding is only for a server running on your own PC at home. Then you log in to your router, forward TCP 25565 (Java) or UDP 19132 (Bedrock) to your PC's local IP, allow the port in your firewall and give friends your public IP. Many Indian broadband and all mobile connections use CGNAT, which blocks this completely. That is the main reason people move to hosting.
