How to back up and restore your game server

By TreeMC · Updated 17 November 2026

A backup is a copy of your world and settings you can go back to after a griefer, a bad plugin, a broken update or a mistake. Make them before every big change and on a schedule.

Back up from the panel

  1. Open the Backups tab and press Create backup. Give it a name like "before 1.21 update".
  2. Wait until it shows as completed. You can download it as a file to keep your own copy.

Each plan has a set number of backup slots. When they are full, delete the oldest one to make room.

Automatic backups

In the Schedules tab, create a schedule (for example every day at 4:00 AM) and add a Create backup task. Many people back up before an automatic restart. Older backups still need to be deleted by hand when the slots fill up.

Back up by hand

Stop the server first so files are not half written, then download the save folder from the Files tab (select it and choose Archive, then download the zip).

Restore a backup

  1. Stop the server.
  2. In the Backups tab, choose the backup and Restore. You can choose to delete current files first, which gives a clean restore.
  3. For a manual backup: delete or rename the current save folder, upload your zip, unarchive it in the same place, and check the folder name matches.
  4. Start the server and check that everything is there.

Restoring replaces what is on the server now. If you are not sure, make a fresh backup of the current state first, so you can go back either way.

Good habits

  • Back up before updating the game, plugins or mods.
  • Keep at least one copy off the server, on your PC or cloud drive.
  • Test a restore once, so you know it works before you need it.
