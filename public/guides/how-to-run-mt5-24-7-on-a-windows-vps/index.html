How to run MT5 24/7 on a Windows VPS

By TreeMC · Updated 17 November 2026

Expert Advisors (EAs) only trade while MetaTrader is open. A Windows VPS keeps MT5 running day and night, with a steady connection, even when your own PC is off.

1. Set up MT5

  1. Connect to your Windows VPS with Remote Desktop: on Windows open Remote Desktop Connection; on Mac or phone use the Windows App. Use the IP, username and password we send you.
  2. Download MT5 from your broker's website and install it.
  3. Log in to your trading account: File → Login to Trade Account.
  4. Copy your EA into the MQL5/Experts folder (File → Open Data Folder), then refresh the Navigator.
  5. Drag the EA onto the chart, tick Allow Algo Trading, and turn on the Algo Trading button in the toolbar. A smiling face or a blue hat on the chart means it is active.

2. Keep it running after you disconnect

  • Close the Remote Desktop window, do not sign out. Signing out closes MT5. Closing the window leaves your session and MT5 running.
  • Set MT5 to start on boot: put a shortcut to terminal64.exe in the Startup folder (press Win+R, type shell:startup). Enable auto login if you want it to come back after a reboot without you.
  • Turn off sleep in Power settings. Servers do not sleep by default, but check it once.

3. Avoid surprise restarts

Windows updates can restart the VPS. In Windows Update, set active hours to your trading hours, and install updates yourself on the weekend when the market is closed. After any restart, open MT5 and check that Algo Trading is on.

4. Pick a location close to your broker

Lower ping to the broker's server means faster order fills. Check the ping at the bottom right of MT5, and choose the VPS location closest to your broker's trade server (often Europe or Singapore). More on ping and locations.

RDP vs VPS for trading and automation

An "RDP" is simply a Windows VPS you use through Remote Desktop. The difference that matters is the operating system:

  • Windows VPS (RDP): runs MT4, MT5, TradingView desktop, browser bots and any Windows software with a normal desktop. Best for most traders.
  • Linux VPS: cheaper per GB and great for Python bots, APIs and crypto bots that do not need a desktop. MetaTrader can run there only with workarounds.

For one or two MT5 terminals, 4 cores and 8 GB of RAM is plenty. Several terminals with many charts need more. See Windows VPS plans or Linux VPS plans.

Trading carries risk. A VPS keeps your software running; it does not make a strategy profitable.
