How to set up a Rust, FiveM or CS2 server

By TreeMC · Updated 17 November 2026

Each of these games has one thing you must do before the server works. They are marked in bold below. Plans for all three are on the game hosting page.

Rust

  1. In the Startup tab set the server name, map size (3000 to 4000 for small servers), seed and max players, then start. The first start generates the map and takes a few minutes.
  2. Join with the F1 console in Rust: client.connect IP:port. The default game port is 28015 UDP.
  3. More settings go in server/<identity>/cfg/server.cfg, for example server.description, server.url, server.headerimage and decay.scale.
  4. Admin: run ownerid YourSteam64ID "name" in the server console, then server.writecfg, and reconnect.
  5. Plugins: install Oxide (uMod) or Carbon, then upload .cs plugin files into oxide/plugins. They load without a restart.
  6. Wipes: Facepunch forces a map wipe on the first Thursday of every month with the game update. To wipe yourself, stop the server and delete the .map and .sav files (and the blueprint database for a full wipe).

FiveM (GTA V roleplay)

  1. Get a license key: log in at portal.cfx.re with your Cfx.re account, create a server key and paste it into the panel (it becomes sv_licenseKey).
  2. Start the server. txAdmin opens on its own port and shows a PIN in the console. Open txAdmin in your browser, enter the PIN, link your Cfx.re account and pick a recipe (QBCore or ESX for roleplay, or a basic server).
  3. Players join from FiveM with F8: connect IP:port. The default port is 30120 (TCP and UDP).
  4. Resources: upload each resource folder into resources/ and add ensure resource-name to server.cfg. Order matters: frameworks and libraries first.

Only use scripts from trusted sources. Leaked or "free premium" scripts often contain backdoors that give strangers admin on your server.

Counter-Strike 2

  1. Get a Game Server Login Token (GSLT): go to steamcommunity.com/dev/managegameservers, use App ID 730, and paste the token into the panel. Without it, the server is only visible on your local network. Your Steam account needs a phone number and must not be limited.
  2. Choose the mode in the Startup tab with game_type and game_mode: 0/1 competitive, 0/0 casual, 1/2 deathmatch, 0/2 wingman.
  3. Pick the start map, for example de_dust2 or de_mirage.
  4. Players join from the CS2 console (enable it in settings): connect IP:port. The default port is 27015.
  5. Set an RCON password, then run admin commands from the game with rcon_password yourpassword and rcon changelevel de_inferno.

Back up configs before big changes: backups for every game.
