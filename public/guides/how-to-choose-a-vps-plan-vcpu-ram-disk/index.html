How to choose a VPS plan

By TreeMC · Updated 17 November 2026

What is a VPS?

A VPS (virtual private server) is your own slice of a powerful server, with its own operating system and full root access. You can install anything: websites, bots, databases, game servers, VPNs.

Compared with shared hosting, where many websites share one setup you cannot change, a VPS gives you guaranteed RAM, your own IP and complete control. The trade-off is that you manage the software yourself.

vCPU, RAM and disk: how much?

You want to runvCPURAMDisk
A few websites or bots24 to 6 GB50 GB
Web app with a database2 to 48 GB80 to 100 GB
Small game server (Minecraft, CS2)2 to 4 fast cores8 GB50 to 80 GB
Several game servers or Docker stacks6 to 816 to 32 GB150 GB+
  • vCPU: more cores help when you run many things at once. Single games care more about per-core speed: that is why we offer AMD Ryzen with DDR5 for game servers.
  • RAM: the most common limit. Leave 20% free so the system never swaps.
  • Disk: NVMe makes databases and game worlds load fast. Count backups and logs too.
  • Location: pick the region closest to your users, see choosing a location.

More detail: VPS vs VDS.

When to upgrade from VPS to VDS

  • CPU sits near 100% at peak times even after you optimise.
  • Performance changes during the day while your own load stays the same.
  • You run a big community game server or a busy database where every millisecond counts.

If RAM is the only limit, a bigger VPS is cheaper than a VDS. We can move you up without reinstalling: ask on Discord. See VDS plans.
