How to import Minecraft server files using SFTP

Move an existing Minecraft server with SFTP: collect the right files, connect securely, upload to the correct folder and test before switching players over.

You already have a world, plugins and a group of players. You don't want a fresh start—you want the same server on the new host. SFTP handles the file transfer, but a careful final copy is what keeps your players' progress intact.

1. Collect the connection details

Find the SFTP hostname, port, username and login method supplied by each host. The game address and SFTP address aren't necessarily the same, and the SFTP port may not be 22. Use the exact values from the panel or support.

In a client such as WinSCP, choose SFTP rather than FTP. Verify the host-key fingerprint against a trusted value from the provider. If a saved server's key suddenly changes, check why before accepting it. You don't need to share credentials with players to move their world.

2. Make a final backup on the old server

Announce a maintenance window, stop the old server cleanly and download a complete backup to a private folder on your computer. Also back up the destination if it already contains anything you want to keep.

Record the Minecraft version, server software, Java requirement and startup JAR name. Move with the same software first. Combining a host move, a Minecraft upgrade and a switch from one server implementation to another creates several possible causes if something breaks.

3. Check what needs to come across

Include the actual world folders, plugins and their data, configuration, permissions and any other files your setup uses. Some software stores dimensions in separate folders; keep the layout appropriate to that software.

External databases need an export and import of their own. Downloading the plugins folder does not copy a database running elsewhere. Likewise, avoid blindly replacing the destination's assigned port, bind address or host-managed startup settings with values from the old host.

4. Upload to the destination

Connect to the new host in a second SFTP session and open the server directory shown by its panel. Upload the contents of your local server folder there. Check that files such as server.properties are at the expected level, not accidentally inside server/server/.

Wait for the transfer queue to finish and inspect failed or skipped items. Retry failures before starting the server. If the host supports archive extraction, an archive can be convenient, but SFTP itself doesn't guarantee a remote unzip feature. Plain folder uploads work without that assumption.

5. Start privately and check the important bits

Confirm the startup file and Java version, then start the destination and read the console. Join with a test account. Check the expected world, inventory, permissions and any plugin that uses a database.

If a new empty world appears, stop immediately and check the uploaded folder layout and level-name. Keep the original backup; don't delete the old world to make the new one look tidy. Missing plugin data and failed transfers should be investigated before players begin building.

6. Switch players over once

Share the new address or update your existing connection record when the checks pass. Keep the old server stopped so progress doesn't split across two copies. Watch the first busy session, then make a fresh backup on the new setup.

Cheap Minecraft hosting in India is only useful for a migration if the plan has enough storage and supports your software. Confirm SFTP availability and any migration assistance before ordering, rather than assuming those details from the price.

Your next steps

  • Confirm both hosts’ SFTP details.
  • Stop both servers for the final copy.
  • Transfer worlds, configuration and external data.
  • Check the upload queue and folder layout.
  • Test player data before announcing the new address.

Questions readers ask

Can I upload an archive through SFTP?

Yes, as a file. Extracting it on the server requires a separate panel feature or permitted server access; the SFTP upload alone does not unpack it.

Why did an empty world start?

Check the world folder path, level-name and server software. Stop the server before correcting the files and preserve the original backup.
